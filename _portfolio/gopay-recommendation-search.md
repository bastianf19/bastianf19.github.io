### Overview
* **Role:** Data Scientist - Growth
* **Company:** GoTo Financial - Gopay (Jakarta, Indonesia)
* **Timeline:** Oct 2025 – Present
* **Tech Stack:** Python, PaiRec, Deep Learning (DBMTL, DIN, MMoE, DCN), Kubeflow, BigQuery, LLM Query Rewriting, Gradient Boosted Trees

### Key Contributions & Achievements
* **Personalized Recommendation in 'Special for You':**
  * Developed and fine-tuned a **Deep Bayesian Multi-Task Learning (DBMTL)** recommendation model serving millions of users in the Gopay home app.
  * Extracted and engineered 200+ user, item, and cross features deployed on Alibaba Cloud's PaiRec platform.
  * Achieved a **+109% UVCVR uplift** and a **+2.86% UVCTR increase** in online A/B testing compared against Smart Adaptive Recommendations (SAR).
* **Deep Multi-Task Algorithm Exploration:**
  * Ran comprehensive benchmarks evaluating Deep Interest Network (DIN), Multi-gate Mixture-of-Experts (MMoE), and Deep Cross Network (DCN), establishing DBMTL as the top-performing architecture for production rollout.
* **Search Retrieval & Relevance Ranking:**
  * Built Gopay Search Query Rewriting and Relevance Ranking models.
  * Leveraged LLM labeling workflows with Gradient Boosting Classifiers to improve semantic matching and item ranking, yielding a **+1% UVCTR increase** and a **2% reduction** in redundant user queries.
