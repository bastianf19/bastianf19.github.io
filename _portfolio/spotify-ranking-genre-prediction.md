### Overview
* **Institution:** University of Edinburgh
* **Timeline:** October – December 2024
* **Tech Stack:** Python, Pandas, Scikit-Learn, PyTorch, Spotify Web API data, Clustering

### Project Summary
* Performed exploratory data analysis across thousands of tracks extracted via the Spotify API, analyzing acoustic attributes (danceability, energy, valence, tempo, acousticness).
* Implemented unsupervised clustering algorithms to identify latent musical groupings and track behavior over time.
* Formulated supervised deep learning and ensemble regressors to predict long-term song popularity trajectories and classify nuanced sub-genres.
